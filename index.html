Analysis

Processing load controls how many frames this tab analyzes. Your browser and operating system control CPU scheduling; a web page cannot limit other tabs or processes. Ultra may make this tab less responsive.

Pixel lock

Limit = ceil(video duration × estimated FPS × percentage / 100). FPS is estimated during playback; starts at 30.

Sensitivity is the minimum change score required to count as a pixel change. The detection method changes how that score is calculated; compressed footage adds noise.

Supported formats

Input formats depend on your browser's built-in decoder. MP4 (H.264), WebM (VP8/VP9), Ogg, MOV, MKV and AVI may work when supported by the browser. Export uses WebM or MP4 depending on browser support.
